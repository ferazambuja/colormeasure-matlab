# Chart resources and source terms

`classic.json` and `sg.json` own grid identities, source-location mappings and
patch identifiers. They contain no numerical palette. The separate
`classic-reference.json` and `sg-reference.json` retain historical expected
values and their interpretation or explicit unavailability; `Run` freezes these as
plain `referenceData` separately from measurements.

| Resource | Source and interpretation |
|---|---|
| Classic layout | ArgyllCMS 3.5.0 `ref/ColorChecker.ti2` |
| SG layout and expected XYZ | `ref/ColorCheckerSG.ti2`; original XYZ retained, but reference colors unavailable because the original white/observer basis is unestablished |
| Classic expected colors | `ref/ColorChecker.cie`; original Lab interpreted under the pinned `scanin` D50 convention |

Original numerical files are retained unchanged in [sources](sources),
including their original identifiers and whitespace. Source location maps,
not raw IDs alone, identify cells. SG's duplicated raw ID 26 does not merge
`C06` and `C07`.

The [structural manifest](../provenance/chart-source.json) and
[reference manifest](../provenance/chart-reference-source.json) pin source
files, consumer interpretation, generated bytes and tooling. The latter also
records the hashes of the existing Python CGATS reader and Lab inverse used
at build time. Runtime MATLAB needs neither Python nor the source checkout
for these resources. Reproduction from the authenticated source distribution:

```sh
python3 tools/charts/generateDefinitions.py --argyll-source /path/to/Argyll_V3.5.0 --check
python3 tools/charts/generateReferences.py --argyll-source /path/to/Argyll_V3.5.0 --python-project /path/to/color-measurement --check
```

Argyll's `ref/ReadMe.txt` explicitly lists these numerical targets under
`ref/License.txt`, the GNU Affero General Public License version 3. The
unmodified terms accompany them in [ARGYLL-AGPL-3.0.txt](ARGYLL-AGPL-3.0.txt).
The application's MIT license does not change these source-derived terms.
The original chart data comes from the
[official ArgyllCMS source distribution](https://www.argyllcms.com/downloadsrc.html).
This repository's [definition generator](../../tools/charts/generateDefinitions.py)
and [reference generator](../../tools/charts/generateReferences.py) create the
application resources from those retained sources; they are not upstream
ArgyllCMS tools.
Standalone student packages retain the original values and numerical source
files, generated data in editable JSON form, application source, generators,
attribution, source manifests and full license. Recipients receive these chart
resources under their retained AGPL-3.0 terms; keep the corresponding source and
notices together when sharing a copy. Other application components retain the
licenses identified in the project README.

Classic illustrations follow the historical Argyll expected-color convention.
SG's expected XYZ remains source data without a rendered reference palette;
Argyll's D50 comparison assumption does not establish its original basis.
Physical chart edition, backing, geometry and specimen measurement conditions
remain unverified. They are positioning illustrations, not a measured specimen,
reference-accuracy claim or quantitative acceptance test. Device RGB columns
are never treated as sRGB. Custom grids have no invented palette. See the
[scientific projection and limitations](../../docs/colorimetry/chart-colors.md).

ColorChecker is an X-Rite/Calibrite product name. Classic names identify
patches; neither the names nor these historical illustrations establish the
reference values of a particular physical chart.
